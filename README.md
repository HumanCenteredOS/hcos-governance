# Purpose

The HCOS™ Governance repository establishes the philosophy, policies, processes, and supporting documentation used to responsibly develop, review, validate, version, maintain, and steward the Human-Centered Operating Systems™ (HCOS™) framework.

As HCOS continues to evolve across multiple repositories, governance provides a consistent approach to stewardship while preserving transparency, accountability, traceability, and continuous improvement.

This repository serves as the central reference for governance practices used throughout the HCOS ecosystem.

---

# HCOS Governship Philosophy

HCOS distinguishes between **governance**, **stewardship**, and **governship**.

Governance protects the integrity of today's system.

Stewardship protects the purpose and health of tomorrow's system.

Governship is the integrated practice of governing through stewardship.

Governship exists to preserve both institutional integrity and human purpose.

Healthy governance should make knowledge easier to understand.

Healthy stewardship should make knowledge more valuable over time.

Together they help HCOS remain trustworthy, adaptable, transparent, and worthy of the people it exists to serve.

# Guiding Principle

# Relationship to the HCOS Ecosystem

The HCOS ecosystem is organized into interconnected architectural layers.

```text
Foundations
      ↓
Governship
      ↓
Knowledge
      ↓
Applications
      ↓
Implementations
```

Each layer serves a different purpose.

| Layer | Purpose |
|--------|---------|
| Foundations | Establishes enduring principles and philosophy. |
| Governship | Defines how HCOS is stewarded and responsibly evolved. |
| Knowledge | Organizes disciplines, models, methods, architectures, and domain expertise. |
| Applications | Provides practical tools and resources. |
| Implementations | Combines HCOS resources into complete solutions. |

Governship connects every layer through shared expectations for stewardship, review, transparency, and continuous improvement.
