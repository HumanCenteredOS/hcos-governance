# Changelog

All notable changes to the HCOS™ Governship Framework are documented here.

## [1.2.0] — 2026-07-29

### Added

- Outcome Stewardship as a core governship principle and responsibility
- Responsibility Across Boundaries as a core principle
- External-Access Governance responsibilities
- Capability Stewardship as a core principle and responsibility
- Evidence and Companion-Instrument Expansion pathway
- Guidance for using a `0.2.0` minor release when evidence reveals supporting architectural layers without requiring a major rewrite
- Outcome Stewardship companion instrument
- External-Access Governance companion instrument
- Capability Stewardship companion instrument
- Expanded governship review questions
- Expanded monitoring and maturity expectations

### Changed

- Updated framework status from Version 1.1 to Version 1.2.0
- Expanded stewardship, decision assessment, implementation, monitoring, ecosystem stewardship, and artifact guidance
- Strengthened the final stewardship question to include measurement, connection, and capability

## [1.1.0]

### Added

- Process integrity and abuse resistance
- Trust controls
- Appeals and restoration
- Pattern detection
- Misuse and coercion safeguards

## [1.0.0]

### Added

- Initial HCOS™ Governship Framework
